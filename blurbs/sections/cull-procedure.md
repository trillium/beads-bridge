## cull procedure — promote / demote to one page
0. Read the target job description FIRST (top of this page) — it is the only culling criterion.
1. Rank every candidate by JD fit: direct enablement proof first, transferable infra second, generic engineering last.
2. Promote ~9–11 bullets total: enablement proof, agent-infra depth, one engineering-credibility line.
3. Demote the rest: table-stakes maintenance, unverified claims, off-JD consulting filler.
4. Never invent metrics, dates, or adoption — unknown numbers stay as [N] with the question stated.
5. Confirm each survivor against open verification findings before locking it in.
