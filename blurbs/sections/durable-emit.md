## durable knowledge — emit it, don't just say it
When durable knowledge emerges (workflow rules, user preferences, corrections,
reusable improvements, missing dependencies), emit it immediately as one fenced
markdown block per scope, paste-ready and self-contained:

```markdown
## durable: <scope>
<paste-ready knowledge — context, evidence boundaries, caveats included>
```

One scope per block (e.g. `resume:resumes-zak`, `project:parlay`), commentary
outside. Shape bodies per the durable object format (`GET /` carries it).
